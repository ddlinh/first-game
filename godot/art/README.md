# Art lives here

**Every image in the game is a PNG in this folder.** The game loads these files at
launch and nothing else — no drawing code runs on the normal path. Repaint any
file (keep the name and canvas size) and the game shows your version next launch.
The code never changes.

- `art/<key>.png` — the live image for that key. **Edit these.**
- `art/_manifest.txt` — the list of keys the game needs. Don't hand-edit; it's
  regenerated by the export tool.
- `art/_templates/<key>.png` — pristine copies of the code-drawn defaults, as a
  tracing base / reference. The loader ignores this subfolder.

## Redesign anything

1. Open `art/<key>.png` in any editor (Krita, Aseprite, Photoshop, GIMP…).
2. Repaint it. **Keep the exact canvas size** in the table below and a transparent
   (RGBA) background.
3. Relaunch (`./play.sh`). Done — no code touched.

To start from the clean default, copy the matching file out of `_templates/`.
To revert one image to the default, **delete** `art/<key>.png` and relaunch — the
fallback regenerates the default and re-writes the file.

## Rules

- **Match the canvas size exactly.** The world scales and anchors each sprite by
  its size; a wrong size mis-scales or mis-floats it.
- **Upright cast (`player`, `survivor_*`, `enemy_*`)**: feet sit near bottom-centre
  (~x = width/2, y ≈ height − 6). The engine anchors by the feet and flips L/R;
  `player`/`player_back` must share silhouette and footing so the turn doesn't jump.
- **Tiles**: fully opaque and edge-to-edge tileable (they repeat across the floor).
- **Motion is still code.** The walk/idle bob-and-squash is applied on top of your
  static image (`walk_anim()` in `scripts/iso.gd`) — you don't draw frames.

### Effects & engine textures — edit with care
These aren't illustrations; they're **functional**. Editing them changes how the

| `shadow` | 128×80 | **contact shadow under everything** — an alpha falloff, tinted in code |
| `light_soft` | 256×256 | **PointLight2D falloff curve** — brightness of every light |

## Adding a *new* image (this one needs code)

The list of keys is set by the code (it asks for them). To add a brand-new image,
add a generator/key in `scripts/art_*.gd`, then run `res://tools/export_art.tscn`
to (re)write the templates, the `art/` files and `_manifest.txt`. Editing an
existing image never needs this.
